# OpenClaw on Oracle Cloud Free Tier

Run a persistent OpenClaw Gateway on an **Oracle Cloud Always Free** VM (Ubuntu). Same idea as [GCP](/install/gcp) or any Linux VPS: install Node, install OpenClaw, run the gateway with systemd, and access the Control UI via SSH tunnel.

## What you need

- Oracle Cloud account ([cloud.oracle.com](https://cloud.oracle.com))
- SSH client (Windows: use PowerShell + `ssh`, or WSL2)
- About 20–30 minutes

## 1) Create an Always Free VM

1. Log in to [Oracle Cloud Console](https://cloud.oracle.com) and choose your region.
2. **Compute** → **Instances** → **Create instance**.
3. **Name:** e.g. `openclaw-gateway`.
4. **Placement:** leave default (or pick a region that has Always Free).
5. **Image and shape:**
   - **Image:** Ubuntu 22.04 (or 24.04 LTS).
   - **Shape:** **VM.Standard.E2.1.Micro** (Always Free) or **VM.Standard.A1.Flex** (ARM, Always Free) — 1 OCPU, 1 GB memory minimum.
6. **Networking:** create or select a VCN; ensure the subnet has **public IP** or use a private subnet + bastion if you prefer.
7. **Add SSH keys:** upload your public key or let Oracle generate a key pair (download the private key).
8. **Create** the instance.

After creation, note the **public IP** of the instance.

## 2) Open SSH (port 22) in the firewall

- **Oracle:** In the instance’s **Subnet** → **Security List** → **Ingress rules**, add:
  - **Source:** `0.0.0.0/0`
  - **Destination port:** `22`
  - **Protocol:** TCP  
  (Restrict source later with your IP if you want.)

- On **Ubuntu**, the `openssh-server` image usually has SSH enabled. If not:
  ```bash
  sudo apt-get update && sudo apt-get install -y openssh-server
  sudo systemctl enable --now ssh
  ```

## 3) SSH into the VM

From your PC (use the path to your private key and the instance’s public IP):

```bash
ssh -i /path/to/your-private-key opc@<PUBLIC_IP>
```

Ubuntu images often use user **ubuntu** instead of **opc**:

```bash
ssh -i /path/to/your-private-key ubuntu@<PUBLIC_IP>
```

If the key was generated by Oracle, the default user is usually **opc** (Oracle Linux) or **ubuntu** (Ubuntu).

## 4) Install Node.js 22

```bash
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs
node -v   # should show v22.x.x
```

## 5) Install OpenClaw

Use the official installer (installs OpenClaw globally and can run onboarding):

```bash
curl -fsSL https://openclaw.ai/install.sh | bash
```

To install without starting the wizard (e.g. you will copy config from another machine):

```bash
curl -fsSL https://openclaw.ai/install.sh | bash -s -- --no-onboard
```

## 6) Configure and run as a daemon

If you ran the installer **with** onboarding, it will have started the wizard. Complete it and choose **install daemon** so the gateway runs under systemd.

If you installed **without** onboarding:

1. Create config and credentials (e.g. copy from your PC or run a minimal onboarding):
   ```bash
   openclaw onboard --install-daemon
   ```
2. Follow the prompts (model provider, API keys, channels, etc.). At the end, choose to install the daemon so the gateway starts on boot and survives logout.

Ensure API keys and secrets are in `~/.openclaw/openclaw.json` or `~/.openclaw/.env` so the systemd service can read them.

## 7) Start and enable the gateway

```bash
openclaw gateway start
# or, if the daemon was already installed:
sudo systemctl --user enable openclaw-gateway
sudo systemctl --user start openclaw-gateway
```

On Linux, the installer typically installs a **user** systemd unit. If `openclaw onboard --install-daemon` enabled lingering, the user service will keep running after you log out. Check:

```bash
openclaw gateway status
```

If the gateway is not running or stops after logout, see [Gateway](/gateway) and [Linux systemd](/platforms/linux) for enabling lingering and user (or system) units.

## 8) Access Control UI from your PC (SSH tunnel)

Do **not** expose the gateway port (18789) to the internet. Use an SSH tunnel from your laptop:

```bash
ssh -i /path/to/your-private-key -L 18789:127.0.0.1:18789 ubuntu@<PUBLIC_IP>
```

(Use `opc` instead of `ubuntu` if your VM user is `opc`.)

Then open in your browser:

**http://127.0.0.1:18789/**

To get a one-time login link with token:

```bash
ssh -i /path/to/your-private-key ubuntu@<PUBLIC_IP> -- openclaw dashboard --no-open
```

Paste the token from that URL into the Control UI.

## 9) Optional: copy config from your PC

If you already have OpenClaw set up on your PC (e.g. Windows with Telegram, bindings, etc.):

1. On the PC, zip the config and state (secrets included; handle securely):
   ```powershell
   # PowerShell (Windows): copy .openclaw from your repo or home
   Compress-Archive -Path "$env:USERPROFILE\.openclaw\*" -DestinationPath openclaw-config.zip
   ```
   Or from WSL/Linux:
   ```bash
   tar -czvf openclaw-config.tar.gz -C ~ .openclaw
   ```
2. Copy the archive to the Oracle VM (e.g. `scp -i key openclaw-config.zip ubuntu@<IP>:~`).
3. On the VM, extract into `~/.openclaw` (e.g. `tar -xzvf openclaw-config.tar.gz -C ~` or unzip into `~/.openclaw`).
4. Restart the gateway: `openclaw gateway restart` (or `systemctl --user restart openclaw-gateway`).

## Summary

| Step | Action |
|------|--------|
| 1 | Create Always Free VM (Ubuntu 22/24, E2.1.Micro or A1.Flex) |
| 2 | Open port 22 in Security List for SSH |
| 3 | SSH into the VM |
| 4 | Install Node 22 |
| 5 | `curl -fsSL https://openclaw.ai/install.sh \| bash` |
| 6 | `openclaw onboard --install-daemon` (or copy existing config) |
| 7 | `openclaw gateway start` / systemd |
| 8 | From PC: `ssh -L 18789:127.0.0.1:18789 ubuntu@<IP>` and open http://127.0.0.1:18789/ |

For production hardening (firewall, fail2ban, non-root user), see [Security](/gateway/security) and your preferred Linux hardening guide. For a Docker-based setup similar to GCP, use [GCP](/install/gcp) as a template and swap `gcloud compute ssh` for `ssh` to your Oracle VM.

# LINE 自動返信エージェント 仕様書

本ドキュメントは、Playwright 経由で LINE Chrome 拡張機能を制御し、AI（OpenClaw）による自動返信および承認フローを実現するシステムの仕様をまとめたものです。

## 1. システム概要
デスクトップ版 LINE 拡張機能の通知および画面テキストを監視し、特定の送信者からのメッセージに対して AI が返信案を作成。ユーザーが Telegram で承認した内容を LINE へ送信します。

## 2. 構成要素
- **`agent.js`**: メインロジック（通知監視、メッセージバッファリング、AI呼び出し、Telegram連携）。
- **`launcher.js`**: ブラウザ制御（Playwright を使用した Chrome 拡張機能の起動、自動ログイン、DOM監視）。
- **`sender.js`**: 送信ロジック（指定されたテキストを LINE 拡張機能の入力欄へ入力し送信）。
- **`.env`**: 認証情報（LINE メールアドレス / パスワード）。

## 3. 主要機能

### 3.1 自動ログイン (Auto-Login) & ウィンドウ設定
セッション切れやブラウザ再起動時に、自動的にログインを試みます。
- **ウィンドウサイズ**: 起動時に `800x1000` のサイズで固定し、デスクトップ上で邪魔にならないように配慮しています。
- **ステルス設定**: 2FA（二要素認証）の頻度を抑えるため、`AutomationControlled` フラグを隠蔽し、正規のブラウザ動作を模倣します。
- **ログイン判定**: 画面上の「メールアドレス」「パスワード」入力欄、および「ログイン」ボタンを全フレーム（iframe 対応）から動的に検知します。
- **サイドバー操作**: 連絡先リスト (`#/friends`) やチャットリスト (`#/chats`) への遷移、およびスクロール操作が可能であることを考慮した設計です。

### 3.2 メッセージ監視
- **ポーリング監視**: `MutationObserver` が効かない制限を回避するため、`document.body.innerText` の変化を定期的にスキャンします。
- **バッファリング**: 連続したメッセージを 10秒間蓄積し、ひとつの文脈として AI に渡します。

### 3.3 AI 承認フロー (Human-in-the-Loop)
- **AI解析**: OpenClaw (`pnpm openclaw agent`) を呼び出し、過去の文脈に基づいた 3 パターンの返信案を生成します。
- **承認**: Telegram に通知された 3 つの選択肢から、ユーザーが番号（1, 2, 3）を返信することで送信が確定します。

## 4. 実行環境
- **OS**: Windows (PowerShell)
- **Node.js**: v22+
- **プロファイル**: `line_ext_profile` 内に LINE 拡張機能がインストールされている必要があります。

## 5. 起動手順
```powershell
cd c:\Users\user\OneDrive\openclaw\line-bot
node agent.js
```

## 6. 注意事項
- **初回認証**: 新しい環境や設定変更後は、一度だけスマホでのログイン許可（認証番号入力）が必要になる場合があります。
- **対象アカウント**: 現在は「コンカフェメモ」という表示名の相手のみに反応するように制限されています。
